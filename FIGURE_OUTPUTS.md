# Figure outputs

The pipeline reporting module exports patent-reporting figures and supporting data. A reviewed example set is stored in `results/rdre_outputs/`.

| Figure | File | Suggested use |
|---|---|---|
| FIG. 1 | `fig01_architecture.png` | System overview; place in architecture/working section if numbering is already allocated |
| FIG. 2 | `fig02_dual_sensor_input.png` | Synthetic sensor inputs |
| FIG. 3 | `fig03_time_frequency_phase.png` | Time-frequency, phase, and power analysis |
| FIG. 4 | `fig04_state_comparison.png` | Reference versus predicted signed state labels |
| FIG. 5 | `fig05_full_state_timeline.png` | Predicted state timeline |
| FIG. 6 | `fig06_event_counts.png` | Preliminary event-evaluation summary only |

The sample outputs are synthetic benchmark outputs. Figure 6 and all reported event metrics must be labelled preliminary until the event evaluator is verified. Do not describe these as physical RDRE experimental results.
